# 01-WP03.T05 有界终止证据

状态：`PASS`

`AgentScopeExecutionGuard` 是 AgentScope 内置 loop 外围的调用边界守卫，不实现第二个 `while` 循环。运行时必须在每次 Model/Tool 调用前经过守卫，并在 Tool 完成后回填新增 Evidence 数量。

## 冻结 reasonCode

| 终止条件 | reasonCode | 独立测试 |
| --- | --- | --- |
| 最大轮次 | `MAX_ROUNDS` | `stopsAtMaximumRoundsAndNeverCallsAgain` |
| deadline | `DEADLINE_EXCEEDED` | `stopsAtDeadlineAndNeverCallsAgain` |
| 外部取消 | `EXTERNAL_CANCELLED` | `stopsOnExternalCancellationAndNeverCallsAgain` |
| 重复动作指纹 | `DUPLICATE_ACTION` | `stopsBeforeRepeatedActionAndNeverCallsAgain` |
| 连续两轮无新 Evidence | `NO_PROGRESS` | `stopsAfterTwoRoundsWithoutNewEvidenceAndNeverCallsAgain` |

每个测试都在终止后再次尝试 Model 和 Tool 调用，并断言计数不再增加；终止只发出一个 `EXECUTION_STOPPED` 审计事件，后续检查返回同一个冻结 reasonCode。

验证命令：

```text
mvn -o -pl opspilot-agent-runtime-agentscope -am test -Dtest=AgentScopeExecutionGuardTest -Dsurefire.failIfNoSpecifiedTests=false
```
