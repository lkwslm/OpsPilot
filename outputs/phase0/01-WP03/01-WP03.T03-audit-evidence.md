# 01-WP03.T03 Middleware/事件审计证据

## 结论

`PASS`

AgentScope Adapter 的事件采集链记录：

- 单调递增 sequence 与 round
- 模型 input/output/cached token Usage
- 基于动作、工具名及规范化参数的 SHA-256 动作指纹
- `sha256:<hex>` checkpoint 身份
- 外部取消信号
- 工具开始/结束及结果状态

正常单工具执行的顺序断言为：`CANCEL_SIGNAL → ROUND_STARTED → MODEL_COMPLETED → ACTION_SELECTED → TOOL_STARTED → TOOL_COMPLETED → CHECKPOINT → ROUND_STARTED → MODEL_COMPLETED → CHECKPOINT`。

## 脱敏与推理隔离

- key 包含 secret/token/password/authorization/apiKey 的值在写入 Sink 前替换为 `[REDACTED]`。
- key 包含 reasoning/chainOfThought/hiddenReasoning 的字段在写入 Sink 前直接删除。
- 审计接口不包含 Prompt、模型响应正文、消息历史或隐藏推理字段。
- 测试将 `top-secret` 与 `must-not-be-stored` 注入工具参数，持久审计字符串中均不存在这两个值。

取消测试证明 `CANCEL_SIGNAL(cancelled=true)` 是唯一事件，之后模型和工具均未被调用。
