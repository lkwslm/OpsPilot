## 进程重启与隔离断言

Testcontainers 启动 PostgreSQL 后，测试按顺序启动两个独立 JVM：

1. 保存进程分别写入 `session-a/checkpoint-a` 与 `session-b/checkpoint-b` 后退出。
2. 恢复进程在前一进程退出后启动，分别读回两个 checkpoint。
3. 恢复进程断言会话状态不相等且没有串读。
4. 使用不同 `serverAgentId` 创建另一 Store，断言无法看到原状态。

数据库主键为 `(server_agent_id, user_id, session_id, state_key)`，状态写入 PostgreSQL `JSONB`；实现没有内存或本地文件回退。
