# 01-WP05.T02 A2A HTTP 与重启恢复证据

状态：`PASS`

`opspilot-a2a` 已在 contract/client/server 包实现 `send`、`stream`、`get`、`cancel` 和 `subscribe`。客户端与服务端只通过 `127.0.0.1` HTTP+JSON 通信，Task 当前状态和可重放事件分别保存在 PostgreSQL 表 `phase0_a2a_task` 与 `phase0_a2a_task_event`。

真实容器测试复用本地 `pgvector/pgvector:pg16`，并先断言镜像 ID 为锁定值。测试在只读取首个 `SUBMITTED` 事件后关闭流与第一组 Client/Server/Store 实例；重建三者后，`get` 取回 `COMPLETED` Task 及 `application/json` Artifact，`subscribe(after=1)` 重放 `WORKING → COMPLETED`，另行验证延迟 Task 可通过 `cancel` 进入 `CANCELED`。

验证结果：2 个测试通过，0 failure，0 error，`BUILD SUCCESS`。Maven 与容器配置目录均位于项目根目录下的 `.tmp`。
